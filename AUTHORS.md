# Authors and Contributions

## Original Project

**Beyond Points Per Game: NBA Player Role Analytics** was originally co-developed by:

- **Kenny Dolgin**
- **Ryan Wenstrom**

Both team members contributed to the shared project, including project design, analytical framing, application development, evaluation, and presentation.

## Current Portfolio

Ryan Wenstrom subsequently created and maintained this portfolio version of the project.

The portfolio includes:

- Repository restructuring and removal of obsolete submission artifacts
- Reconstruction of the raw-to-application data pipeline
- Validation of player eligibility rules and analytical calculations
- Reconstruction and correction of team-season records
- NBA Cup championship handling
- Correction of incomplete 2024-25 game data using final standings
- Regeneration of application-ready CSV and JSON files
- GitHub Pages deployment cleanup
- Methodology and data-source documentation
- Recruiter-facing README development
- Final testing and quality assurance

## AI-Assisted Development

AI-assisted tools were used to support coding, debugging, documentation, and validation during the portfolio refactor.

Project framing, methodological decisions, data-quality review, interpretation, and final acceptance remained human-directed.
